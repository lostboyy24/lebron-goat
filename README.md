# LeBron James: The Case for the GOAT

A single-page static website arguing that LeBron James is the greatest basketball player of all time, with a full career story, records, a GOAT argument, a fair "counterarguments and rebuttals" section, a timeline, season-by-season stats, and off-court impact.

**Live site:** https://lostboyy24.github.io/lebron-goat/

- Pure HTML + CSS (no frameworks, no JavaScript, no external assets or hotlinked photos)
- Responsive layout, CSS-only mobile nav, smooth-scroll anchors
- Lakers purple and gold palette, with Cavs / Heat / Lakers / 76ers accent colors on the timeline and charts
- Statistics are through the 2025-26 NBA season, checked against Basketball-Reference, NBA.com, ESPN, StatMuse and Wikipedia

Independent fan project; not affiliated with LeBron James, the NBA or any team.
